About This Project

The Cybersecurity Assessment and Awareness System (CAAS) is a research and development project aimed at enhancing the network security posture of small and medium enterprises (SMEs) in Windhoek. Many SMEs operate with limited IT budgets and staff, leaving them exposed to preventable threats such as weak passwords, missing backups, and unpatched, misconfigured services.

CAAS was built using the Prototyping Model: an initial working version of the system was refined incrementally, in six stages, based on stakeholder feedback, until it satisfied the functional requirements identified through questionnaires, interviews, and document analysis with participating SMEs.

What CAAS Does
  • Runs a structured cybersecurity assessment and produces a security score and risk level
  • Delivers interactive awareness training with quizzes across 8 core topics
  • Performs a lightweight technical network scan and flags insecure open ports
  • Presents consolidated insights on a manager-facing dashboard
  • Exports assessment, training, and vulnerability reports as PDF, Excel, or CSV
Technology Stack

HTML, CSS, Bootstrap, JavaScript (frontend) · Python/Flask (backend) · SQLite (database) · Chart.js (dashboard charts) · Python socket/subprocess/ipaddress (network scanning)
